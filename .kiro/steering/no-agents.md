# Запрет на использование субагентов

НИКОГДА не используй субагентов (invoke_sub_agent) для любых задач.

- Всю работу выполняй сам напрямую
- Не делегируй задачи специализированным агентам
- Сам пиши код, сам читай файлы, сам запускай команды
- Это относится ко всем типам задач: разработка, исследование, рефакторинг, выполнение задач из спеки
